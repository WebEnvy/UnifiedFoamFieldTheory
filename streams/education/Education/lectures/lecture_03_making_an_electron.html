Step 1

The dipole pattern

Watch the faces. On one side they push outward; on the opposite side they pull inward. This is a dipole — the simplest asymmetric vibration.

This pattern doesn't represent the electron. It is the electron. The vibration frequency of this mode is the electron's mass.

Watch the cell vibrate for a few seconds
Step 2

The pattern persists

Drag the amplitude slider all the way down. Even at the tiniest displacement, the pattern is the same — the geometry sustains it. There is no minimum energy below which the electron "turns off."

Now drag it up. The pattern gets louder but never changes shape. This is quantisation — the mode is discrete, not continuous.

Drag the amplitude slider to minimum, then to maximum
Step 3

Interface mode

Notice both face types vibrate — hexagons and squares. The T₁ᵤ mode is the only eigenmode that spans both face types. Every other mode is confined to one type or the other.

In the foam language: the electron lives at the interface between bubble (hex) and void (square). That's what B + V = D means — matter is displacement at the boundary.

Watch which faces move — both types participate
Step 4

Mass from geometry

The electron mass formula:
m_e = r₁ · M_P · exp(−(E−F)(2Δ+√Δ)/16)

Every symbol is an integer from this shape: r₁ ≈ 2.438 (eigenvalue), E = 36 (edges), F = 14 (faces), Δ = 17 (discriminant). One cell, zero free parameters, 0.002% accuracy.

This cell has been vibrating in this pattern for 13.8 billion years.
